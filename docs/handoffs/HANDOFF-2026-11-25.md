### What went wrong in the first v3 notebook

The test run showed that all 16 tree points were in one plot (`CLBJ_043`). The 80/20 split of plots put that plot in the test set. The training set had 0 tree points, the classifier knew only GRSS, WATR, and SHADE, and the test accuracy was 30.4% (7 of 23). The OOB and resubstitution accuracy were both 1.0 because the classifier only separated three easy classes.

Consequences:
- The "60-75% expected accuracy" in the README, `docs/RUN_CODE.md`, and the notebook was a prediction without data. It was wrong. All three now hold measured numbers or no numbers.
- The Phase 2 test accuracy (87.5%) compares stems of one plot with other stems of the same plot. It does not measure generalization to new locations.
- The statement in the handoff of 2026-11-24 that "Phase 3 methodology is sound" was not correct for the first version of the notebook. Do not rewrite that handoff. This file replaces it.

### Cause

The April and May 2022 download of `vst_apparentindividual` has 156 records (event `vst_CLBJ_2021`, dated from 2022-04-06) in only two plots (`CLBJ_036`, `CLBJ_043`). Only `CLBJ_043` has georeferenced stems that pass the filters. The download for 2022-04 to 2022-12 has 412 records (345 individuals) and gives 65 stems in 5 plots. Details are in `docs/PLAN.md`.
