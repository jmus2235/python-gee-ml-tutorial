**Key insight:** Lower accuracy in Phase 3 is **expected and correct**. It measures true generalization to new locations, not memorization of spectrally similar neighbors from the same plot.

**Spatial autocorrelation addressed:**
- Phase 2 problem: Stems from same plot appear in both training and test sets → inflated accuracy
- Phase 3 solution: Entire plots assigned to training OR test, never both → independent evaluation
