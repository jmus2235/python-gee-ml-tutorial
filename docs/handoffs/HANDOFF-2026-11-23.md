### Data and Methods

**Year selected:** 2022
- Reflectance: `HSI_REFL/002/2022_CLBJ_6` (BRDF-corrected, sensor NIS1)
- CHM: `CHM/001` (RELEASED status)
- VST: April-May 2022 bouts (RELEASE-2026)

**Training data:**
- **Tree species:** 16 stems from VST field data (JUVI: 4, QUST: 9, ULCR: 3)
  - Applied geoNEON formula to compute stem coordinates from plot-relative positions
  - Queried NEON location API for plot point UTM coordinates (214 unique locations)
  - Converted UTM Zone 14N → WGS84 lon/lat with pyproj
  - Filtered: live trees, canopy position ["Full sun", "Partially shaded", "Mostly shaded"], height ≥ 1.0 m
  - Dropped QUMA3 (only 1 sample, cannot split)
- **Non-tree classes:** 30 manually selected points (GRSS: 10, WATR: 10, SHADE: 10)
  - Threshold-based generation attempted but produced sparse samples (2/0/2)
  - User manually identified coordinates from reflectance image
- **Total:** 46 training points across 6 classes
- **Class numbering:** 0=JUVI, 1=QUST, 2=ULCR, 7=GRSS, 8=WATR, 9=SHADE (gaps where classes were dropped)

**Classifier:**
- Random forest: 100 trees, 382 predictors (381 reflectance bands + 1 CHM)
- Used unclipped composite (not airshed-clipped) because tree points fall outside airshed boundary
- Training samples: 37 of 38 (1 point at no-data location)
- Test samples: 8 of 8

**Results:**
- OOB accuracy: **83.78%** (OOB error: 16.22%)
- Test accuracy: **87.5%** (7 of 8 correct)

### Issues Resolved

1. **VST filtering too strict → only 3 initial stems**
   - Original filters: "Full sun" or "Open grown", height ≥ 3 m
   - 77% of VST records missing stemDistance/stemAzimuth coordinates
   - Most trees in "Mostly shaded" category, not "Full sun"
   - **Solution:** Relaxed to include "Mostly shaded", lowered height threshold to 1.0 m
   - Result: 17 stems → dropped QUMA3 (1 sample) → 16 final

2. **Threshold-based non-tree points failed**
   - NDVI band naming issue (used 'nd' instead of 'NDVI')
   - Thresholds too strict for 2022 image characteristics
   - Sampling returned only 2 GRSS, 0 WATR, 2 SHADE
   - **Solution:** User manually identified coordinates for 10 points per class
   - Result: 30 non-tree points with known-good locations

3. **Reference points map not displaying**
   - Tree FeatureCollection missing 'class' property (all points had class='Unknown')
   - **Solution:** Fixed tree_fc creation to assign class numbers (0, 1, 2) based on taxonID
   - Result: Map displays correctly with colored diamond markers

4. **Training sample extraction failing → only 1 of 38 samples**
   - 37 of 38 training points fell outside valid data extent
   - `CLBJ_composite_airshed` (clipped to airshed) masked out VST tree locations
   - VST plots are distributed across TOS area, not confined to 90% flux airshed
   - **Solution:** Use unclipped `CLBJ_composite` for sampling and classification
   - Result: 37 of 38 training samples extracted (1 at no-data pixel)

5. **Confusion matrix dimension mismatch**
   - GEE returns 10×10 matrix (classes 0–9) even though only 6 classes used
   - Code tried to create DataFrame with 3×3 labels (tree species only)
   - **Solution:** Extract 6×6 submatrix for classes [0,1,2,7,8,9] using numpy indexing
   - Result: Confusion matrix displays correctly

6. **Classification map showing grey (no color)**
   - Palette not being applied
   - **Solution:** Use 10-color palette (class values 0–9) with grey for unused classes 3–6
   - Result: Classification displays with correct colors (yellow, green, magenta, light green, blue, black)

## Decisions Made

1. **2022 as target year:** Best VST data availability (spring bouts match flight), sensor continuity (NIS1), released CHM
2. **Relaxed VST filters:** Included "Mostly shaded" canopy position, lowered height threshold to 1.0 m to get sufficient samples
3. **Dropped QUMA3:** Only 1 sample cannot be split 80/20
4. **Manual non-tree coordinates:** Threshold approach failed, user manually selected 10 points per class from image
5. **Used unclipped composite:** VST points fall outside airshed, so classify full TOS area not just airshed
6. **Class numbering 0,1,2,7,8,9:** Kept original Phase 1 numbers for non-tree classes, gaps where CELA/PRME/ULAL/QUMA3 dropped

## Notes

- The notebook shows the threshold-based approach and its failure (2/0/2 points), then the manual selection solution (10/10/10 points). This is educational — shows what didn't work and how it was resolved.
- Classification works well despite sparse training data. Manual non-tree point selection appears to have chosen representative locations.
